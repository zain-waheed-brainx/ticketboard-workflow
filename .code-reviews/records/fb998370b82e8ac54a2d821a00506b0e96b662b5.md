## Summary

Bumps ticketboard to 0.3.0. Ticket refs now default to the project's initials (e.g. WWL-8) instead of TIX, with a new `board prefix` command, a `PUT /api/config` `idPrefix` route and a Settings field that rename every ticket (folder, id, grill-me title, shared plan file) and keep old refs resolving. Branch name suggestions no longer carry the ticket ref, use short type keys (`enh/`, `fix/`), and starting a ticket refuses a branch another ticket owns. Skill docs and README are updated to match. No stack marker matched (no package.json), so a generic review was applied. The rename logic and ref-free suggestions are sound, but the default branch name used when no branch is given still honors a saved pattern that contains the ticket ref, and the rename is not atomic.

A retry does recover (renamed tickets are skipped), so the impact is limited. *(correctness)*
  - status: fixed
