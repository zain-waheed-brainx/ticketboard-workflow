## Summary

Bumps the ticketboard plugin to 0.9.5 and turns `bin/board` into a sh/Node polyglot launcher. The shell prefix looks for Node 18+ on PATH, in nvm, then Homebrew, and `exec`s the file with it. It prints an install hint and exits 127 if none is found. Node sees the added lines as a string expression plus comments, so the JS body is unchanged. No stack marker matched, so a generic review was applied. The quoting, glob fallthrough (non-matching globs fail the `-x` test), version gate and `exec "$0" "$@"` are sound. Note: when node is not on PATH, the lexicographic nvm glob may pick an older installed version (for example v18 before v24). This still meets the stated Node 18+ requirement, so it is not raised as a finding.
