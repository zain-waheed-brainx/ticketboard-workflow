## Summary

Adds a short, meaningful `{slug}` for ticketboard branch names. A new `branchSlug` helper drops filler words, abbreviates long words and never cuts mid-word; tickets can carry their own `slug` (set via `board new --slug`, `board set slug=`, the New ticket and Start dialogs, or suggested by Claude in the ticket skill). The logic is sound: slugs pass through `slugify`/`cleanSlug` and `validBranch` before reaching git, the server routes pass the new field through, and clearing a slug falls back to the title-derived one.
