## Summary

Adds a "just me" vs "team" mode to ticketboard (v0.4.0). In me mode the project profile lives in .board/project.json and .board/ is hidden via .git/info/exclude; in team mode the profile is the committed ticketboard.project.json and .board/ goes in .gitignore. Adds `board mode`, a PUT /api/config mode switch, a settings UI, and gates plan sharing to team mode. Stack: none of the framework markers matched (plain Node plugin, no package.json), so a generic review was applied. Re-review: all three earlier findings were re-evaluated against the current code and are resolved.
